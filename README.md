# Market-Structure-Regime-Model-for-MTF
Developed a market structure regime classification model that recursively compresses price information into multi-scale trend states. The resulted regime labels were used as filters for momentum-based trading strategies. 

This model is a final model for integrating quantitative trading system. (4th project) The trading system would be integrated a market regime models (v1, v2), alpha generation models (v1, v4), and risk management model into a unified signal generation and automated trading framework.
